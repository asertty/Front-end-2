## 오늘의 프론트 수업

![image](https://github.com/user-attachments/assets/4b309685-5aff-425b-8c30-d949dc6adfc4)

    위 그림과 같이 버튼을 생성하고 hr를 사용하여 입력하는 박스에 숫자를 키우거나 작게 하고 
    버튼을 누를 시 초기화가 되도록 하였다.

|+ document는 전체를 상징한다.

![image](https://github.com/user-attachments/assets/887c8c75-511a-4bcd-be76-de9b39c5326b)

    innerhtml를 사용하여 위에 계속 원히는 단을 검색 할 수 있도록 하는데 
    배열 형식으로 저장되기 때문에 배열 [0]을 넣어 사진과 같은 화면을 만들었다.

전체코드
-

    <!DOCTYPE html>
    <html lang="ko">
    
    <head>
        <title>구구단</title>
    </head>
    
    <body>
    
        <h2>구구단 구하기(0이면 초기화)</h2>
        <input type="number" id="value">
        <input type="button" value="계산" onclick="gugudan()">
        <hr>
    
        <div id="result"></div>
    
        <script>
            function gugudan() {
                let dan = document.getElementById("value").value;
                let resultDiv = document.getElementById("result");
    
                if (dan == 0) {
                    resultDiv.innerHTML = ''; 
                } else {
                    resultDiv.innerHTML += `<h4>${dan} 단 출력</h4>`;
                    for (let i = 1; i < 10; i++) {
                        resultDiv.innerHTML += `<span>${dan} X ${i} = ${dan * i} <br></span>`;
                    }
                }
            }
        </script>
    </body>
    
    </html>
